# Qwen OpenAI-compatible Chat API

- **Resource ID:** 03
- **Publisher:** Alibaba Cloud Model Studio
- **Official source:** https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions

## Reading notes

The guide covers OpenAI-compatible Chat Completions requests, model IDs, messages and multimodal input. It can help estimate SDK migration effort. Verify tool calling, thinking controls, structured output, streaming and error semantics per model.

## Enterprise selection questions

- Can the application reuse the OpenAI SDK
- Are image/audio/video inputs needed
- Do endpoint region and API-key scope satisfy data-location requirements
- Are there differences from native APIs?
