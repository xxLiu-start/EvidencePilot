# Qwen3.5-35B-A3B official model card

- **Resource ID:** 01
- **Publisher:** Qwen Team / Hugging Face
- **Official source:** https://huggingface.co/Qwen/Qwen3.5-35B-A3B
- **Purpose:** Model architecture, parameter scale, context length, license, capabilities and self-hosting.

## Reading notes

The card describes a multimodal 35B-total / about 3B-active MoE model, native 262K context extensible to about 1.01M, and deployment examples for Transformers, vLLM and SGLang. Verify license, hardware, framework compatibility and business-task performance before production.

## Enterprise selection questions

- Does the workload need vision/video
- Is the license suitable for commercial use
- Does the target GPU and serving stack support the architecture
- Has long-context quality been tested on real data?
