# DeepSeek thinking mode and reasoning effort

- **Resource ID:** 06
- **Publisher:** DeepSeek API Docs
- **Official source:** https://api-docs.deepseek.com/guides/thinking_mode/
- **Purpose:** Understand thinking controls, reasoning effort and multi-turn tool-call context requirements.

## Reading notes

The guide documents thinking toggles and reasoning-effort mappings, plus sampling-parameter caveats. In tool-use conversations, required reasoning fields must be carried forward as documented. Use higher effort only where business evaluation shows benefit.

## Enterprise selection questions

- Which requests need stronger reasoning
- Are reasoning tokens included in budget and latency
- Is multi-turn tool context handled correctly
- What is the quality/cost curve across effort levels?
