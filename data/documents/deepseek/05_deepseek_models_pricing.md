# DeepSeek API models and pricing

- **Resource ID:** 05
- **Publisher:** DeepSeek API Docs
- **Official source:** https://api-docs.deepseek.com/quick_start/pricing/
- **Purpose:** Compare API models, context, output limits, cache-hit pricing and output pricing.

## Reading notes

The official page lists model IDs, context and output limits, tool/API capabilities, input and output prices, and cache-hit prices. Prices and aliases can change. Record the retrieval date and model version in any cost model.

## Enterprise selection questions

- What is the input/output token mix
- Can stable prompts achieve cache hits
- How do peak rates and concurrency limits affect TCO
- Does an alias move to a new model version?
