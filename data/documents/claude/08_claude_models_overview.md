# Claude models overview

- **Resource ID:** 08
- **Publisher:** Anthropic Claude Platform
- **Official source:** https://platform.claude.com/docs/en/models/overview
- **Purpose:** Compare model positioning, context, output limits, speed and pricing entry points.

## Reading notes

The overview consolidates active model capabilities, context windows, output limits, speed and links to pricing. These are dynamic fields. Build a shortlist from the official page, then evaluate candidates on the organization's own task set.

## Enterprise selection questions

- Is the workload reasoning-, speed- or cost-sensitive
- Are context and output limits sufficient
- Are tool use and vision required
- How will model updates affect reproducibility?
