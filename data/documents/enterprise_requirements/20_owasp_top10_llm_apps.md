# OWASP Top 10 for LLM Applications 2025

- **Resource ID:** 20
- **Publisher:** OWASP GenAI Security Project
- **Official source:** https://genai.owasp.org/resource/owasp-top-10-for-llm-applications-2025/
- **Purpose:** Check common LLM application security risks.

## Reading notes

The list covers prompt injection, insecure output handling, training-data poisoning, denial of service, supply-chain vulnerabilities, sensitive information disclosure, insecure plugin design, excessive agency, overreliance and model theft. It focuses on application risks, not model-only evaluation.

## Enterprise selection questions

- Are user input and retrieved content separated by trust boundaries
- Are outputs validated
- Are tool permissions least-privilege
- Are sensitive data leakage, denial of service and supply-chain risks addressed?
